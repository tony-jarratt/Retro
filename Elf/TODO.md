# Always Time for a Bow: to-do

Guiding rule: **it has to be fun.** When in doubt, tune for feel (forgiving, fast to restart, fair enemies) over realism.

## Done
- Ice platforms (screens 2, 4, 5): the elf slides and keeps momentum, including into jumps.
- Rolling baubles (screens 1, 3, 4, 5): a bonk knocks you back and stuns you briefly. It never costs a life.

- Upper-floor scenery: a few small wall pieces per screen (clocks, pictures, wreaths, shelves, bunting and so on), placed only in clear spots.
- Window events: an owl pops up and blinks, or a star twinkles in a window, every few seconds.
- Title music: a light festive 16-bar loop in the P1 chip style (`js/music.js`), starts on the first key press and fades out when the game starts. M mutes it.

## Decided against
- Trap doors: the screens work well as they are.

## Ideas still to add
- More obstacles: toy trains on a loop, spilled marbles, wind-up toys, stacks of boxes.
- Animated scenery in the workshop (turning cogs, running conveyor belt).
